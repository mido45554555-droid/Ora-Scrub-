# ORA — custom medical scrubs

Bilingual (Arabic/English) e-commerce site for made-to-measure scrubs.

| Folder | What it is |
|---|---|
| [`frontend`](frontend/README.md) | Website: Next.js 16, React 19, Tailwind, next-intl |
| [`backend`](backend/README.md) | Order API: Node.js, Express, MariaDB/MySQL |

New here? Start with **[HANDOVER.md](HANDOVER.md)** — full setup from scratch (Arabic).

Run the backend first (`npm run setup` once, then `npm start`), then the
website (`npm run dev`). Full steps are in each folder's README.
